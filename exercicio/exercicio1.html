Seletores Compartilhados







Seletor de Atributo


O que é?

O seletor de atributo no CSS é uma ferramenta usada para encontrar e estilizar elementos HTML com base na presença, no valor ou em partes do valor de um atributo específico.


Qual sua utilização?

Aplicar um estilo diferente em links que abrem em outra aba (target="_blank") ou que apontam para arquivos PDF.


Exemplo:


                /* Estilo para links que abrem em nova aba */
                a[target="_blank"] {
                 color: red;
                }

                /* Estilo para links de arquivos PDF */
                a[href$=".pdf"] {
                color: green;
                font-weight: bold;
                }




Seletor Descendente


O que é?

O seletor descendente em CSS é um combinador representado por um espaço em branco ( ) entre dois ou mais seletores. Ele serve para selecionar um elemento que esteja contido (em qualquer nível de profundidade) dentro de um elemento ancestral específico.


Qual sua utilização?

Estilizar todos os links (< a >) que estão dentro de um rodapé (footer) ou menu (nav).


Exemplo:


            
            /* Seleciona todos os < p > que são descendentes de um elemento com a classe .caixa */
            .caixa p {
            color: blue;
            font-size: 16px;
            }




Seletor Filho Direto


O que é?

O seletor de filho direto (representado pelo símbolo >) em CSS é um recurso utilizado para selecionar apenas os elementos que são filhos imediatos de um elemento pai. Isso significa que ele ignora elementos que estão aninhados mais profundamente na estrutura (como netos ou bisnetos).


Qual sua utilização?

Sua principal utilização é garantir a aplicação de estilos de forma específica e controlada, evitando que regras de CSS "vazem" e afetem submenus, listas aninhadas ou outras estruturas internas parecidas.


Exemplo:


            
                /* Seleciona apenas os < li > que são filhos diretos de .menu-principal */
                .menu-principal > li {
                color: blue;
                font-weight: bold;
                }




Seletor de Irmãos Gerais


O que é?

Seletor de Irmãos Gerais (representado pelo caractere til ~ em CSS) é um combinador que seleciona todos os elementos que compartilham o mesmo elemento pai e aparecem depois de um elemento especificado.


Qual sua utilização?

É usado quando você precisa aplicar um estilo a todos os elementos de um mesmo nível que vêm após um marco inicial (como um título ou um botão), e não apenas ao primeiro.


Exemplo:


            
                h2 ~ p {
                color: green;
                font-weight: bold;
                }




Seletor de Pseudoclasse


O que é?

Um Seletor de Pseudoclasse em CSS é uma palavra-chave adicionada a um seletor que especifica um estado especial do elemento selecionado.


Qual sua utilização?

Ele permite aplicar estilos a um elemento não apenas com base na sua estrutura na árvore do documento, mas também com base em fatores externos, como o comportamento do usuário, o histórico de navegação ou o estado de um elemento de formulário.


Exemplo:


            
                seletor:pseudoclasse {
                propriedade: valor;
                }




Seletor de Pseudoelemento


O que é?

O seletor de pseudoelemento em CSS é uma palavra-chave adicionada a um seletor que permite estilizar partes específicas do HTML que não existem como nós separados na árvore do documento.


Qual sua utilização?

Eles são amplamente utilizados para inserir conteúdo decorativo, estilizar a primeira letra ou linha de um texto, ou customizar elementos de formulários sem a necessidade de poluir o código com tags HTML extras.


Exemplo:


            
                seletor::pseudoelemento {
                propriedade: valor;
                }
